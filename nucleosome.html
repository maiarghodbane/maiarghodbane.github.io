MOLECULAR DYNAMICS PROJECT

Molecular Dynamics of Nucleosome 1KX5

Studying how post-translational histone modifications may influence nucleosome compaction, DNA–histone interactions and chromatin structural dynamics using all-atom molecular dynamics simulations.

Project Overview

This project focuses on the nucleosome, the fundamental unit of chromatin organization. I work on the structure PDB 1KX5 and investigate how histone post-translational modifications may affect nucleosome dynamics, compaction and DNA–protein contacts.

What I Did

  • Prepared the nucleosome structure PDB 1KX5 for molecular dynamics simulations.
  • Assigned force fields for both DNA and histone proteins using AMBER tools.
  • Generated topology and coordinate files using TLEaP.
  • Performed solvation, ion neutralization and system preparation.
  • Ran molecular dynamics simulations using PMEMD.
  • Analysed trajectories using CPPTRAJ and Python.

Analyses Performed

RMSD • RMSF • PCA • distance analysis • DNA–protein contact analysis • trajectory visualization • structural interpretation.

Skills Developed

AMBER workflow • TLEaP • PMEMD • CPPTRAJ • Python scripting • Linux environment • biomolecular system preparation • trajectory analysis • structural biology interpretation.

What I Can Do Independently

  • Run MD simulations using AMBER/PMEMD.
  • Analyse trajectories with CPPTRAJ.
  • Write Python scripts for RMSD, RMSF, PCA, distance and contact analyses.
  • Interpret structural changes in relation to biological function.
