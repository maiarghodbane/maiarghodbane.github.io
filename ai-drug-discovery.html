What I Did

  • Selected BACE1 as a therapeutic target for a beginner drug discovery workflow.
  • Collected bioactivity data from ChEMBL using the ChEMBL webresource client.
  • Cleaned and prepared IC50 datasets using Python and Pandas.
  • Converted IC50 values into pIC50 values for activity prediction.
  • Generated Lipinski descriptors using RDKit.
  • Generated molecular fingerprints and descriptors for machine learning.
  • Built and evaluated a Random Forest regression model.

What I Can Do Independently
